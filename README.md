# MathX Pro — Advanced Calculator

MathX Pro is an advanced web-based calculator built using **HTML, CSS and JavaScript**. It provides basic calculations along with scientific, programmer and useful mathematical tools in a clean and responsive interface.

## Features

* Basic arithmetic operations
* Addition, subtraction, multiplication and division
* Percentage calculation
* Decimal and positive/negative operations
* Scientific calculations
* Trigonometric functions
* Logarithm and natural logarithm
* Square and square root
* Power calculations
* Pi and Euler's number
* Factorial calculation
* Programmer mode
* Bitwise operations
* Calculation history
* Quadratic equation solver
* Percentage calculator
* GCD and LCM calculator
* Unit converter
* Statistics calculator
* Keyboard support
* Responsive design for desktop and mobile

## Calculator Layout

The basic calculator follows a standard calculator arrangement:

```text
AC   ⌫   %   ÷
7    8   9   ×
4    5   6   −
1    2   3   +
0    .   ±   =
```

4. Start using the calculator.
